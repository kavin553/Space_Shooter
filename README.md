## 🎮 Gameplay Instructions

🕹️ How to Play:

* 🚀 Drag to move your spaceship
* 🔫 Tap to shoot bullets
* 💎 Collect crystals to increase score
* ☄️ Destroy asteroids
* ❤️ Avoid losing all lives
